# Software Requirements Specification (SRS)

This directory contains all SRS source documents and the compiled PDF for the TeaRoutePay system.

## Contents Structure

- `final/` — Compiled PDF (`SRS_TeaRoutePay.pdf`)
- `requirements/` — Individual requirement specification documents

## Requirements Documents

| File | Description |
|---|---|
| `desktop-functional-requirements.md` | Functional requirements for the office desktop application |
| `mobile-functional-requirements.md` | Functional requirements for the collector mobile application |
| `non-functional-requirements.md` | Non-functional requirements (performance, security, reliability, etc.) |
| `collector-requirements.md` | Tea collector role requirements and pain points |
| `farmer-requirements.md` | Farmer/supplier requirements and expectations |
| `office-owner-requirements.md` | Owner and office staff requirements |
| `bank-transfer-requirements.md` | Payment process and bank transfer requirements |
| `deduction-rules.md` | Loan, advance, fertilizer, and tea deduction business rules |
| `qr-requirements.md` | QR code generation and scanning requirements |
| `offline-first-storage-requirements.md` | Offline-first mobile storage requirements |
| `end-of-day-sync-requirements.md` | End-of-day synchronization requirements |
| `monthly-receipt-requirements.md` | Monthly payment receipt generation requirements |
| `sms-confirmation-requirements.md` | SMS notification and communication requirements |
