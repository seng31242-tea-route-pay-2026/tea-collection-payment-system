# Farmer / Supplier Requirements

## Overview

Farmers are key stakeholders of the TeaRoutePay system. They provide tea leaves and depend on accurate collection records and monthly payments. The system aims to improve payment transparency, collection accuracy, and communication.

---

# Farmer Activities

- Provide tea leaves to collectors
- Receive loans and fertilizer support
- Receive tea for personal use
- Receive payments and receipts
- Review deduction details

---

# Farmer Pain Points

- Manual record errors
- Missing or duplicate collection records
- Difficulty tracking deductions
- Delayed payment verification
- No SMS payment confirmation

---

# Farmer Data Requirements

| Data Item | Description |
|---|---|
| Farmer ID | Unique farmer identification |
| Farmer Name | Farmer full name |
| Contact Number | Mobile number |
| Address | Residential address |
| QR Code Data | QR-based farmer identification |
| Collection Records | Tea collection history |
| Loan Records | Loan details |
| Deduction Records | Fertilizer and tea deductions |
| Payment Records | Monthly payment history |

---

# Functional Requirements

## FR-01 – Farmer Identification
The system shall support QR code or farmer ID-based identification.

## FR-02 – Collection Recording
The system shall record tea collection details and tea leaf weight accurately.

## FR-03 – Deduction Management
The system shall manage loan, fertilizer, and tea deductions.

## FR-04 – Payment Calculation
The system shall calculate farmer payments accurately.

## FR-05 – Receipt Generation
The system shall generate payment receipts.

## FR-06 – SMS Notifications
The system shall send payment confirmation SMS notifications.

## FR-07 – Offline Support
The system shall support offline collection recording.

## FR-08 – Data Validation
The system shall reduce duplicate entries and human errors.

---

# Farmer Expectations

- Accurate payment calculations
- Clear deduction visibility
- Reliable collection records
- Faster payment confirmation
- Better transparency

---

# Farmer Outputs

- Payment receipts
- SMS notifications
- Collection summaries
- Deduction summaries

---

# Expected Improvements

- QR-based farmer identification
- Reduced manual work
- Improved record accuracy

---

# Conclusion

TeaRoutePay will improve farmer payment accuracy, collection reliability, and communication while reducing manual errors in the tea collection process.
