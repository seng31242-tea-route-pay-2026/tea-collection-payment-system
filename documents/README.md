# Documents

This directory contains the primary deliverables and documentation for the SENG 31242 System Design Project.

## Contents Structure

- `srs/` - Software Requirements Specification (SRS) markdown source and PDF
- `sds/` - Software Design Specification (SDS) markdown source and PDF
- `Final_Design_Report.pdf` - The combined Final Design Report
- `pitch/` - Idea pitch deck and project approval form
- `architecture/decisions/` - Architectural Decision Records (ADRs)
- `meetings/` - Meeting notes and log forms
