# Prototypes

This directory contains design-phase prototypes for the TeaRoutePay system.

## Contents Structure

- `wireframes/` - Wireframe source files
- `figma-exports/` - Exported Figma screens
- `low-fidelity/` - Early design sketches and low-fidelity prototypes
- `mobile-app/` - Mobile application prototype screens
- `desktop-app/` - Desktop application prototype screens
- `user-feedback/` - Feedback collected for prototype improvements
