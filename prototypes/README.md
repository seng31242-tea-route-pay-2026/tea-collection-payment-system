# Prototypes

This directory contains design-phase prototypes for the TeaRoutePay system.

## Contents Structure

- `desktop-wireframes/` — Low-fidelity wireframes for the office desktop application
- `mobile-wireframes/` — Low-fidelity wireframes for the collector mobile application

## Desktop Wireframes

Located in `desktop-wireframes/`. Covers:

| Wireframe | Purpose |
|---|---|
| `farmer-management-wireframe.png` | Manage farmer records and registrations |
| `collection-records-wireframe.png` | View synchronized tea collection records |
| `deduction-management-wireframe.png` | Manage loans, fertilizer, and other deductions |
| `payment-calculation-wireframe.png` | Calculate monthly farmer payments |
| `receipt-report-wireframe.png` | Generate receipts and business reports |

See `desktop-wireframes/desktop-wireframes-overview.md` for full descriptions.

## Mobile Wireframes

Located in `mobile-wireframes/`. Covers:

| Wireframe | Purpose |
|---|---|
| `qr-scan-wireframe.png` | Scan farmer QR codes for identification |
| `farmer-details-wireframe.png` | Display farmer information after QR scan |
| `tea-weight-entry-wireframe.png` | Record tea collection weight |
| `offline-records-wireframe.png` | View records saved offline before synchronization |
| `sync-status-wireframe.png` | Monitor synchronization progress and status |

See `mobile-wireframes/mobile-wireframes-overview.md` for full descriptions.
